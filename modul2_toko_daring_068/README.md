# Modul 2 — Analisis Kebutuhan Data (Tema: Toko Daring)

Parameter dari 3 digit terakhir NIM `068`:
- Dua digit terakhir: 68
- P = (68 mod 9) + 1 = 6
- Maksimum barang per transaksi = P + 2 = 8
- Nilai diskon/denda harian parameter = Rp6.000
- Estimasi volume transaksi = 40 + 5P = 70 transaksi/hari
