## 2. Ringkasan Dasar Teori

### 2.1 Perintah SELECT

`SELECT` digunakan untuk mengambil data dari satu atau beberapa kolom dalam tabel. Perintah ini dapat dikombinasikan dengan klausa lain agar informasi yang ditampilkan sesuai kebutuhan.

### 2.2 Penyaringan Data

Klausa `WHERE` digunakan untuk menyaring baris. Operator yang digunakan dalam praktikum meliputi:
- `IN` untuk memilih beberapa nilai tertentu.
- `BETWEEN` untuk memilih rentang nilai.
- `LIKE` untuk mencari pola teks.
- `IS NULL` dan `IS NOT NULL` untuk memeriksa nilai kosong.
- Operator pembanding seperti `=`, `<`, dan `>`.

### 2.3 Pengurutan dan Pembatasan

`ORDER BY` mengurutkan hasil berdasarkan kolom tertentu. `ASC` berarti urutan menaik, sedangkan `DESC` berarti urutan menurun. `LIMIT` membatasi jumlah baris yang ditampilkan.

### 2.4 Fungsi Skalar

Fungsi skalar menghasilkan nilai untuk setiap baris yang diproses. Fungsi yang digunakan antara lain:
- `CONCAT()` untuk menggabungkan teks.
- `UPPER()` untuk mengubah teks menjadi huruf kapital.
- `FORMAT()` untuk memformat angka.
- `DATE_FORMAT()` untuk mengubah tampilan tanggal.
- `IFNULL()` untuk mengganti nilai `NULL`.
- `DATEDIFF()` untuk menghitung selisih tanggal.
- `CASE` untuk menghasilkan nilai berdasarkan kondisi.

## 4. Jawaban Titik Analisis

### 4.1 Mengapa alias tidak dapat langsung digunakan pada WHERE?

Alias yang dibuat pada bagian `SELECT` umumnya tidak dapat dipanggil langsung pada `WHERE`, karena secara logis kondisi `WHERE` diproses sebelum daftar kolom `SELECT`. Solusinya adalah menuliskan kembali ekspresi atau menggunakan subkueri.

Contoh:

```sql
SELECT stok_min_barang - stok_barang AS kurang
FROM barang
WHERE stok_min_barang - stok_barang > 0;
```

### 4.2 Apa perbedaan NULL dan string kosong?

`NULL` menunjukkan nilai yang tidak tersedia atau tidak diketahui, sedangkan string kosong (`''`) merupakan nilai teks yang ada tetapi tidak berisi karakter. Untuk mencari nilai `NULL`, gunakan `IS NULL`, bukan `= NULL`.

### 4.3 Bagaimana menghitung subtotal penjualan?

Subtotal dihitung dengan mengalikan jumlah barang dengan harga satuan:

```sql
SELECT
    qty_detail_penjualan,
    harga_satuan_detail_penjualan,
    qty_detail_penjualan * harga_satuan_detail_penjualan AS subtotal
FROM detail_penjualan;
```

Perhitungan total seluruh detail transaksi memerlukan fungsi agregat seperti `SUM()` dan pembahasan pengelompokan data.
