## 1. Tujuan Praktikum

Praktikum Modul 2 bertujuan untuk memahami proses analisis kebutuhan pengelolaan data dalam suatu organisasi. Melalui praktikum ini, mahasiswa diharapkan mampu mengidentifikasi aktor, proses bisnis, entitas, aturan bisnis, kebutuhan informasi, serta elemen data yang diperlukan dalam perancangan database.

## 2. Dasar Teori

Analisis kebutuhan data merupakan tahap awal dalam perancangan basis data. Tahap ini dilakukan untuk mengetahui jenis data yang diperlukan, bagaimana data digunakan, serta hubungan antara data dalam kegiatan operasional organisasi.

Dalam analisis kebutuhan data, terdapat beberapa komponen penting, yaitu proses bisnis, entitas, aturan bisnis, kebutuhan informasi, matriks CRUD, dan kamus data. Seluruh komponen tersebut digunakan sebagai dasar untuk merancang struktur database yang sesuai dengan kebutuhan organisasi.

## 3. Prosedur Pengerjaan

Prosedur pengerjaan Modul 2 dilakukan melalui beberapa tahapan sebagai berikut:

1. Membuka folder praktikum basis data pada Visual Studio Code.
2. Membuat file kebutuhan data dengan nama p02_kebutuhan_data_25430068.md.
3. Menentukan studi kasus organisasi KlikKita Store.
4. Mengidentifikasi aktor dan proses bisnis yang terdapat dalam organisasi.
5. Mengidentifikasi dokumen sumber yang digunakan dalam kegiatan operasional.
6. Menentukan entitas dan elemen data yang dibutuhkan.
7. Menyusun aturan bisnis dan kebutuhan informasi.
8. Membuat matriks CRUD untuk mengetahui aktivitas pengelolaan data.
9. Menyusun kamus data awal beserta penanggung jawabnya.
10. Menentukan kebutuhan non-fungsional dan isu kualitas data.
11. Membuat contoh nota pesanan sebagai dokumen sumber.
12. Mengerjakan latihan program loyalitas dan perbaikan kebutuhan sistem.
13. Menyimpan seluruh hasil pekerjaan dalam format Markdown.

## 4. Hasil Praktikum

Hasil praktikum Modul 2 berupa dokumen analisis kebutuhan data KlikKita Store yang berisi identifikasi proses bisnis, aktor, dokumen sumber, entitas, aturan bisnis, kebutuhan informasi, matriks CRUD, kamus data, kebutuhan non-fungsional, dan isu kualitas data.

Dokumen tersebut digunakan sebagai dasar untuk tahap perancangan basis data pada modul berikutnya.

## 5. Pembahasan

Berdasarkan hasil analisis kebutuhan data pada KlikKita Store, diketahui bahwa kegiatan toko daring membutuhkan pengelolaan data yang saling berhubungan. Data pelanggan, produk, keranjang, pesanan, pembayaran, dan pengiriman harus disimpan secara terstruktur agar kegiatan operasional dapat berjalan dengan baik.

Penyusunan aturan bisnis membantu menentukan ketentuan dalam proses transaksi, seperti penggunaan kode produk yang unik, pembatasan jumlah stok, serta penyimpanan harga produk ketika transaksi dilakukan.

Matriks CRUD digunakan untuk mengetahui proses pembuatan, pembacaan, perubahan, dan penghapusan data. Sementara itu, kamus data membantu menjelaskan fungsi setiap elemen data dan pihak yang bertanggung jawab terhadapnya.

Melalui latihan program loyalitas, rancangan kebutuhan data juga dikembangkan agar dapat mendukung pencatatan poin dan penukaran poin pelanggan.
