## 1. Tujuan Praktikum

Menyiapkan lingkungan kerja MariaDB melalui XAMPP, mengamankan akun root, membuat akun kerja dan basis data praktikum, mengatur hak akses pengguna, serta menginisialisasi dan mengelola repositori Git dan GitHub untuk proyek basis data.

## 2. Ringkasan Dasar Teori

MariaDB merupakan sistem manajemen basis data relasional dengan arsitektur klien-server. Dalam praktikum ini MariaDB dijalankan melalui XAMPP dan dapat diakses menggunakan command line maupun phpMyAdmin.

Pengelolaan pengguna dan hak akses MariaDB dilakukan menggunakan perintah seperti `CREATE USER`, `GRANT`, dan `SHOW GRANTS`. Pemberian hak akses perlu disesuaikan dengan kebutuhan pengguna agar menerapkan prinsip least privilege.

Git digunakan untuk mencatat perubahan berkas melalui commit, sedangkan GitHub digunakan sebagai tempat penyimpanan repositori secara daring.

## 4. Jawaban Titik Analisis

### Titik Analisis 1

Label tombol pada XAMPP dapat bertuliskan MySQL, sedangkan server basis data yang digunakan dalam praktikum adalah MariaDB. Perintah SQL dasar pada keduanya memiliki banyak kesamaan, tetapi untuk konfigurasi dan fitur spesifik server perlu memperhatikan dokumentasi MariaDB.

### Titik Analisis 2

Ketika pengguna mencoba masuk tanpa memberikan password dengan opsi yang tidak sesuai, MariaDB dapat menghasilkan `ERROR 1045`. Hal tersebut menunjukkan bahwa proses autentikasi gagal karena kredensial yang diperlukan tidak diberikan atau tidak sesuai.

### Titik Analisis 3

Basis data sistem seperti `information_schema` dapat tetap terlihat oleh pengguna karena digunakan untuk menyediakan informasi metadata server. Sementara itu, akses terhadap basis data lain bergantung pada hak akses yang diberikan kepada pengguna.

### Titik Analisis 4

Mode autentikasi cookie pada phpMyAdmin membuat pengguna memasukkan kredensial ketika melakukan login, sehingga password tidak perlu ditulis secara langsung di dalam berkas konfigurasi phpMyAdmin.

## 5. Hasil Latihan dan Modifikasi

### E.1 Akun Tamu

Dibuat akun `tamu_068` dengan hak akses `SELECT` saja terhadap basis data `kopma_068`.

Pengujian dilakukan dengan mencoba membuat tabel:

```sql
CREATE TABLE uji (id INT);
```

Perintah tersebut ditolak oleh MariaDB dengan `ERROR 1142` karena akun `tamu_068` tidak memiliki hak untuk membuat tabel.

Hasil tersebut menunjukkan bahwa pembatasan hak akses telah berhasil diterapkan.

### E.2 Skrip Rerunnable

Skrip SQL dimodifikasi agar dapat dijalankan berulang kali menggunakan:

```sql
CREATE DATABASE IF NOT EXISTS
```

dan:

```sql
CREATE USER IF NOT EXISTS
```

Skrip kemudian diuji kembali dan dapat dijalankan tanpa membuat database atau pengguna duplikat.
